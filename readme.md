# 💈 Barber Booking Bot

Telegram-бот для автоматизації онлайн-запису клієнтів у барбершоп.

Бот дозволяє клієнтам самостійно обрати послугу, майстра, дату та вільний час, а адміністратору — керувати послугами, майстрами, розкладом та записами через Telegram.

Проєкт розроблений на Python з використанням `aiogram` та `SQLite` і може бути адаптований під конкретний бізнес.

## 🚀 Встановлення

### 1. Клонування репозиторію

```bash
git clone https://github.com/loandinger-maker/barber-booking-bot.git
cd barber-booking-bot
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

### 3. Активація віртуального середовища

#### Windows

```bash
.venv\Scripts\activate
```

#### Linux / macOS

```bash
source .venv/bin/activate
```

### 4. Встановлення залежностей

```bash
pip install -r requirements.txt
```

## 🔐 Налаштування

Створіть файл `.env` у корені проєкту.

Приклад:

```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_id
```

### Де отримати `BOT_TOKEN`

Створіть Telegram-бота через **@BotFather** та отримайте API-токен.

### Де дізнатися `ADMIN_ID`

Використайте Telegram-бота, який показує ваш Telegram ID, або отримайте ID іншим зручним способом.

> Ніколи не публікуйте справжній `BOT_TOKEN` у GitHub.

## 🗄 База даних

Проєкт використовує SQLite та асинхронну бібліотеку `aiosqlite`.

Основні сутності бази даних:

- `users` — користувачі;
- `services` — послуги;
- `masters` — майстри;
- `master_schedule` — розклад майстрів;
- `appointments` — записи клієнтів.

База даних використовується для зберігання інформації про клієнтів, послуги, майстрів, розклад та записи.

---

## 🔔 Сповіщення

Бот підтримує сповіщення, пов'язані із записами.

Адміністратор отримує сповіщення про:

- нові записи;
- скасовані записи.

Клієнти отримують нагадування про свої записи.

---

## 📊 Керування записами

Кожен запис має певний статус.

Використовуються такі статуси:

```text
active
completed
cancelled
```

Це дозволяє адміністратору розділяти поточні, завершені та скасовані записи й отримувати статистику.
